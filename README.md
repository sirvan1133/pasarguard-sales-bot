# PasarGuard Telegram Sales Bot

ربات فروش و تمدید خودکار اشتراک برای پنل **PasarGuard** بدون وابستگی خارجی (فقط کتابخانه استاندارد Python + `qrencode`).

## امکانات
- 🛒 خرید اشتراک جدید با حجم و مدت دلخواه + قیمت‌گذاری پلکانی
- 🔄 تمدید اشتراک با تخفیف ویژه (قابل تنظیم از پنل ادمین)
- 🪙 پرداخت تتر (BEP20 / BSC) با نرخ لحظه‌ای و **تایید خودکار روی بلاک‌چین**
- 💳 پرداخت کارت‌به‌کارت با جلوگیری از ثبت کد پیگیری / هش تکراری
- 👛 کیف پول داخلی (شارژ حساب و پرداخت آنی)
- 🎁 تست رایگان هفتگی (با بازه و حجم قابل تنظیم)
- 🎟 کد تخفیف و 🤝 سیستم دعوت دوستان (رفرال)
- 📦 مدیریت اشتراک‌ها (وضعیت لحظه‌ای، QR کد، تغییر لینک ساب `revoke_sub`، تمدید)
- 👨‍💻 پشتیبانی مستقیم داخل ربات با قابلیت پاسخ ادمین
- ⏳ یادآور خودکار قبل از انقضا یا اتمام حجم
- 🗄 بکاپ روزانه و 📊 گزارش فروش شبانه برای ادمین
- 👑 پنل ادمین کامل برای تغییر همهٔ پارامترها و ارسال پیام همگانی

## نصب تک‌خطی روی سرور (Ubuntu / Debian)

```bash
curl -fsSL https://raw.githubusercontent.com/sirvan1133/pasarguard-sales-bot/main/install.sh | sudo bash
```

در هنگام نصب فقط **توکن ربات** و **آیدی عددی ادمین** پرسیده می‌شود و بقیه مراحل (`python3`, `qrencode`, دانلود ربات و ساخت سرویس `systemd`) به‌صورت خودکار انجام می‌شود.

سپس در صورت نیاز اطلاعات پنل (`PANEL_URL`, `PANEL_USER`, `PANEL_PASS`) را در `/opt/sales-bot/.env` وارد کرده و سرویس را ری‌استارت کنید:

```bash
systemctl restart sales-bot.service
```

سایر تنظیمات (شماره کارت، آدرس تتر، قیمت هر گیگ، درصد سود، تخفیف تمدید، تست رایگان، مشخصات پنل و `آیدی گروه پنل`) مستقیم از داخل ربات در بخش **👑 پنل ادمین** قابل تغییر است.
> 💡 **نکته:** منظور از **آیدی گروه پنل (`GROUP_ID`)** شمارهٔ گروهی در پنل PasarGuard است که کاربران جدیدِ ساخته‌شده توسط ربات عضو آن می‌شوند تا اینباندهای آن گروه را دریافت کنند (در اکثر پنل‌ها همان `1` است).
