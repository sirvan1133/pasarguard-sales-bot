# PasarGuard Telegram Sales & Reseller Bot

ربات فروش، تمدید و پنل نمایندگی خودکار برای پنل **PasarGuard** بدون نیاز به نصب کتابخانهٔ اضافه (فقط Python استاندارد + `qrencode`).

## قابلیت‌های کلیدی
- **فروش و تمدید خودکار:** خرید با حجم و مدت دلخواه، بسته‌های حجم قابل تنظیم، قیمت‌گذاری پلکانی و تمدید با تخفیف ویژه.
- **پرداخت کارت‌به‌کارت هوشمند:** تولید مبلغ یکتای ۴۸ ساعته (رقم رندوم برای شناسایی دقیق واریز) + امکان فعال‌سازی فوری همراه با دکمهٔ مسدودسازی فیش جعلی توسط ادمین.
- **تایید خودکار تتر (BEP20 / BSC):** نرخ لحظه‌ای تتر + بررسی خودکار تراکنش روی بلاک‌چین بدون نیاز به تایید دستی.
- **پنل نمایندگی (`💼 پنل نمایندگی`):** حداقل شارژ اولیه `500` گیگ، تعرفهٔ ثابت، ساخت تکی و گروهی (Bulk)، سقف حجم تک‌اکانت، حداکثر ۳ ماه، مدیریت و حذف اکانت با برگشت وجه.
- **کیف پول داخلی:** شارژ حساب، پرداخت آنی و انتقال موجودی بین کاربران (`💸 انتقال موجودی`).
- **تست رایگان و رشد فروش:** تست هفتگی قابل تنظیم، کد تخفیف، تخفیف همگانی کمپین، سیستم دعوت دوستان (رفرال) و قفل عضویت اجباری کانال.
- **مدیریت کامل از تلگرام (`👑 پنل ادمین`):** تغییر تمام قیمت‌ها، شماره کارت، ولت، مشخصات پنل، جستجو و مدیریت کاربر، پیام همگانی، حالت تعمیر و نگهداری، هشدار سفارش معوق، گزارش شبانه، بکاپ روزانه و آپدیت تک‌کلیک از گیت‌هاب.

## نصب تک‌خطی روی سرور (Ubuntu / Debian)

```bash
curl -fsSL https://raw.githubusercontent.com/sirvan1133/pasarguard-sales-bot/main/install.sh | sudo bash
```

در هنگام نصب فقط **توکن ربات** و **آیدی عددی ادمین** پرسیده می‌شود و بقیه مراحل خودکار انجام می‌شود.
پس از نصب، وارد **`👑 پنل ادمین`** در تلگرام شوید و اطلاعات پنل (`آدرس پنل`، `یوزر پنل`، `رمز پنل`، `آیدی گروه پنل`) و شماره کارت / آدرس تتر خود را تنظیم کنید.
> 💡 **نکته:** منظور از **آیدی گروه پنل (`GROUP_ID`)** شمارهٔ گروهی در پنل PasarGuard است که کاربران جدید عضو آن می‌شوند (در پنل‌های تک‌گروهه همان `1` است).
