# ربات فروش و نمایندگی اختصاصی PasarGuard

ربات جامع فروش، تمدید، پشتیبانی و **نمایندگی اختصاصی (White-Label Sub-Bot)** برای پنل **PasarGuard** — نوشته شده با Python استاندارد (بدون هیچ وابستگی خارجی، فقط `python3` و `qrencode`).

---

## قابلیت‌های فروش و مشتریان

| بخش | توضیحات |
| :--- | :--- |
| **خرید و تمدید خودکار** | انتخاب بسته‌های حجم قابل تنظیم یا حجم دلخواه، مدت دلخواه، قیمت‌گذاری پلکانی و تخفیف ویژهٔ تمدید |
| **کارت‌به‌کارت هوشمند** | تولید مبلغ یکتای ۴۸ ساعته (رقم رندوم برای شناسایی دقیق واریز) + فعال‌سازی آنی با بررسی بعدی ادمین |
| **تایید خودکار تتر (BEP20)** | دریافت نرخ لحظه‌ای تتر (نوبیتکس / والکس) + بررسی خودکار هش تراکنش روی شبکهٔ BSC بدون نیاز به تایید دستی |
| **کیف پول و انتقال موجودی** | نمایش آیدی عددی کاربر در `/start` و کیف پول، شارژ حساب، پرداخت آنی، گزارش ۱۵ تراکنش آخر (`📜 گزارش تراکنش‌ها`) و انتقال اعتبار با آیدی عددی یا `@username` (`💸 انتقال موجودی`) |
| **تست رایگان هفتگی** | دریافت خودکار اکانت تست (حجم، مدت و فاصلهٔ روزانه قابل تنظیم از پنل ادمین) |
| **مدیریت اشتراک‌های من** | مشاهدهٔ مصرف لحظه‌ای، دریافت مجدد QR کد، تمدید مستقیم و تغییر لینک سابسکریپشن (`revoke_sub`) |
| **کد تخفیف و رفرال** | اعمال کد تخفیف روی فاکتور، لینک دعوت اختصاصی و ارسال خودکار کد تخفیف پاداش به معرف |
| **پشتیبانی و راهنمای اتصال** | ارسال تیکت متنی/تصویری به ادمین با قابلیت پاسخ مستقیم + راهنمای نصب برنامه‌های اندروید، iOS و ویندوز |

---

## سیستم نمایندگی و ربات اختصاصی (White-Label)

| قابلیت | نحوهٔ عملکرد |
| :--- | :--- |
| **شرایط نمایندگی** | حداقل شارژ اولیهٔ قابل تنظیم (پیش‌فرض `500` گیگ) + تعرفهٔ ثابت هر گیگ (`5,000` تومان) + تایید مدیریت |
| **ساخت تکی و گروهی (Bulk)** | ساخت اکانت تکی با نام دلخواه یا ساخت همزمان تا ۳۰ اکانت با یک دستور + محدودیت سقف حجم تک‌اکانت و حداکثر ۳ ماه |
| **حذف و برگشت وجه** | حذف اکانت‌هایی که کمتر از ۵٪ حجمشان مصرف شده و برگشت خودکار مبلغ به کیف پول نماینده |
| **ربات اختصاصی و دو کیف پول نماینده** | ثبت توکن ربات جدید توسط نماینده ← راه‌اندازی سرویس مجزا با دیتای ایزوله، برند/کارت/قیمتِ خودِ نماینده، **کیف پول بالادستی** (خرید از بالادست) + **کیف پول فروش** (واریزی زیردست‌ها و مشتریان) |
| **حسابداری زنجیره‌ای و مهلت ۲۴ ساعته** | قفل فایل بین‌پروسسی (`flock`)، کسر خودکار هزینهٔ عمده از کیف پول بالادست، هشدار کمبود موجودی، **فرصت ۲۴ ساعته (۱ روزه) پس از اتمام موجودی همراه با هشدار قطع** و تسویهٔ خودکار هنگام شارژ بعدی، و مخفی‌ماندن کامل اطلاعات پنل PasarGuard در ربات نماینده |

## امکانات پنل مدیریت (`👑 پنل ادمین`)

| دسته | ابزارهای مدیریتی |
| :--- | :--- |
| **قیمت‌گذاری و پلن‌ها** | تغییر قیمت پایه هر گیگ، بسته‌های حجم پیش‌فرض، آستانه حجم عمده، درصد سود زیر/بالای آستانه، تخفیف تمدید و تخفیف کمپین |
| **پرداخت و امنیت** | تغییر شماره کارت، صاحب کارت، آدرس تتر BEP20، حالت کارت‌به‌کارت (فوری/مشتریان قدیمی/دستی)، سقف سفارش در انتظار و مسدودسازی ۲۴ ساعته/دائمی فیش جعلی |
| **کاربران و اطلاع‌رسانی** | جستجوی کاربر (تلگرام/پنل)، تغییر حجم/تاریخ/وضعیت اکانت، شارژ دستی کیف پول، پیام همگانی، قفل عضویت کانال و حالت تعمیر و نگهداری |
| **گزارش، بکاپ و آپدیت** | آمار ساب‌های ربات و کاربران آنلاین پنل، وضعیت نودها، یادآور سفارش معوق، گزارش فروش شبانه، بکاپ کامل زیپ (`.json` و `.env` ربات اصلی + همهٔ ربات‌های نماینده به ربات بکاپ اختصاصی) و آپدیت تک‌کلیک از گیت‌هاب (مختص ادمین اصلی همراه با ری‌استارت خودکار همهٔ ربات‌های نماینده) |

## نصب تک‌خطی روی سرور (Ubuntu / Debian)

<div dir="ltr">

```bash
curl -fsSL https://raw.githubusercontent.com/sirvan1133/pasarguard-sales-bot/main/install.sh | sudo bash
```

</div>

در زمان نصب فقط **توکن ربات** و **آیدی عددی ادمین** پرسیده می‌شود و نصب پیش‌نیازها، ساخت سرویس `systemd` و راه‌اندازی خودکار انجام می‌گردد.
پس از نصب، وارد **`👑 پنل ادمین`** در تلگرام شوید و مشخصات پنل و روش‌های پرداخت را تنظیم کنید.

---

## متغیرهای فایل `.env`

| متغیر | توضیح |
| :--- | :--- |
| `BOT_TOKEN` | توکن ربات تلگرام دریافتی از `@BotFather` |
| `ADMIN_IDS` | آیدی عددی ادمین(ها) — برای چند ادمین با کاما جدا کنید |
| `PANEL_URL` | آدرس پنل PasarGuard (مثلاً `https://panel.example.com:8443`) |
| `PANEL_USER` / `PANEL_PASS` | نام کاربری و رمز عبور ادمین پنل PasarGuard (قابل تنظیم از داخل ربات) |
| `GROUP_ID` | آیدی عددی گروه در پنل PasarGuard که کاربران جدید عضو آن می‌شوند (در پنل‌های تک‌گروهه همان `1` است) |
